## 核心用户任务

1. 第一眼找到资产、当前价格与 K 线。
2. 知道当前价格与均线、最近关键位的关系。
3. 知道下一步观察哪个位置，以及什么变化需要重新评估。

验收不以显示指标的数量为目标，而以图表和文字能否帮助用户完成这三个任务为目标。

## 信息架构

导航只包含：市场总览、行情、工具。BTC / ETH 在行情页内切换；原 `/btc`、`/eth` 可分享地址继续保留。市场总览的内容结构、四个平级工具卡不在本轮重新设计，仅在后续实施中统一视觉令牌。

桌面顺序：紧凑导航 → 资产与价格栏 → 图表约 68% / 研究约 32% 的同一工作区。

手机顺序：导航 → 资产与价格 → 周期 → K 线和成交量 → 行情解读 → 关键位 → 观察条件 → 多周期。图表先于详细解读，不横向堆卡、不依赖横滑读取正文。

不添加大标题营销区、额外资产导航、下单按钮、搜索、登录或空的 VIP 宣传块。

## 右侧四个区块

| 区块 | 必需字段 | 展示约束 |
| --- | --- | --- |
| 行情解读 | 当前价格与当前周期 EMA 的相对位置、短周期变化的事实依据 | 一句结论加一句证据；不冒充作者观点，不输出成功率 |

| 接下来关注 | 上/下方各一个条件；条件对应的周期、确认状态 | 最多两条，不把盘中穿越写成确认突破，不等同于开仓或止损指令 |
| 多周期对照 | 各周期状态与一致/冲突的依据、各自时间与可用状态 | 一周期一句话，不再展开四套全量指标；概念稿只用已有截图的三个周期示意，不虚构日线结论 |

## 图表与研究联动

- 点击右侧某条关键位，高亮图上对应价格线或区域，并允许再次点击取消。
- 周期切换同时更新图表与对应研究；旧周期结果不可在新周期标题下短暂显示。
- 图层设置负责 EMA10/20/50/200、成交量和关键位显隐；隐藏绘图线不删除研究所需计算。
- 默认分析最新行情。缩放、拖动历史窗口只改变画布，不悄悄改变当前研究；如以后增加历史研究，必须显式进入回看模式。
- 开高低收与成交量读数只在悬停、点击或键盘选中时出现，不长期覆盖图表。
- 保留键盘定位、屏幕阅读器图表摘要、选中读数及状态播报。
- 详细来源、缓存、原始 K 线表、可见区间统计不占用主页面；内部数据链保留完整。

## 已落实的数据边界

### 当前价格与确认结构分离

- `latestPosition`：同资产、同计价单位、同周期的最新价格与 EMA 关系，可随当前 K 线变化。
- `confirmedStructure`：使用已完成周期，关键位突破/失守只能按明确规则确认。
- 当前价、24 小时变化应优先使用一致行情口径；不能在隐藏来源文字后把不同单位或不同价格含义混成一个报价。
- 图中示例叙述不进入生产配置。正式文案必须从经过验证的数据与规则得到。

### 客观关键位与人工策略分离

- 算法候选可复用参考项目中的摆动点、Pivot、区间 Fibonacci 与成交高密度节点聚类思路。
- “最近”与“权重最高”不同：先构造、验证候选，再按距离选择默认展示位置；权重不是胜率或可靠概率。
- 摆动点需要后续 K 线确认，必须区分极值时间和确认时间，不能把事后可知的位置画成当时已知信号。
- 人工关键位、作者策略继续是独立的私有内容路径；不得用算法结果填充未发布的 Wise 判断。

### 成交分布为估算

- 参考算法基于 OHLCV，按价格桶分配成交量，计算 POC 与成交价值区上下沿；不是逐笔成交、持仓成本或订单簿流动性。
- 页面保留简短“估算”标签，不再重复来源长文。
- 计算窗口固定，不跟随用户拖图变化。成交量缺失、全零、窗口不足、非法数据时返回不可用，不产生看似精确的关键位。
- 价格显示按资产精度与区域宽度决定；不以任意小数位制造精确性。

### 更新与降级

- 延续现有同源图表增量刷新方向；不从浏览器直接请求第三方 API。
- 多周期确认研究按各周期边界和服务端缓存更新，不每 5 秒重复拉取所有周期的完整历史。
- 用户只需看到简洁更新时间；真实 stale/error 必须可识别，不能因为清理来源文字而隐藏延迟。
- 价格可用、研究不可用时仍显示价格与图表，研究明确说明未能更新；不编造结构、补零或继续显示不适用于当前周期的结论。
- 保留 source、scope、updatedAt/asOf、retrievedAt、cache、stale 和算法版本的内部合同。

## 公开研究与未来 VIP

本轮已将客观多周期研究公开，与身份解耦；这属于明确的产品权限调整，不是把普通用户伪装成 VIP。

未来人工策略仍在服务端鉴权后读取，不能进入公开缓存。当前设计不放空的 VIP 锁定大块，也不添加未接入 AI 的展示结果。

关键位事件历史、回踩确认、牛熊转换与 AI 属于后续独立范围；需要真实持久化与时序验证，本轮不设计虚构历史列表。

- 画布：`#F5F5F7`；图表/表面：`#FFFFFF`。
