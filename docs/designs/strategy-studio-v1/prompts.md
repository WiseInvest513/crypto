# 人工策略发布台 V1 — Image Gen 提示摘要

生成方式：内置 Image Gen；既有 BTC 行情工作台截图仅作为品牌和视觉参考，不是编辑目标。

## 桌面

生成 1440 × 1000 的完整私有策略发布台。保持 Wise Crypto 的真白 / 冷灰 / 近黑视觉系统，琥珀只用于人工策略，禁止绿色。页面包含草稿、待复核、已发布工作流；左侧连续表单覆盖策略概况、价格区域、确认与失效、审核与风险；右侧 sticky 发布预览、发布检查与版本信息；底部包含保存草稿、提交复核和发布策略。所有字段为空，不使用示例价格、胜率、回报或自动建议。

## 手机

将桌面概念严格转译为 390 × 844 单列界面。保持相同文案、配色、字号和控件体系；预览与发布检查移到表单之后的折叠区，底部操作栏保留至少 44px 触控高度；页面无裁切和横向溢出，不新增营销区或假数据。
