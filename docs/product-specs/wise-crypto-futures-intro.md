# Wise Crypto 合约入门学习工具

> 状态：V2 内容与学习体验重设计完成
> 日期：2026-09-07
> 公开入口：`/tools`
> 独立学习 URL：`/tools/futures-intro`

## 1. 产品定位

“合约入门”是 Wise Crypto 工具区中的学习型工具，不是新的顶层栏目、独立学院、
交易信号页或开户链接。它与四个计算器处于同一工具体系，但使用适合学习任务的目录、
进度和答题交互；现有四个计算器继续保持四张同权入口。

产品帮助新用户按固定顺序理解合约规则、风险和图表观察方法。学习完成只表示用户完成了
教育内容，不代表具备盈利能力，也不能用于生成交易方向、胜率、收益承诺或 VIP 权限。

## 2. 信息架构

### `/tools`

- 保留四个计算器的四列同权布局。
- 在计算器区域之前增加一条独立的“合约入门”学习入口。
- 入口展示 `5 章 · 26 关`、快速路径和完整路径，但不展示 XP、等级、徽章或排行榜。
- 不新增顶部导航项；当前导航仍为市场总览、行情、工具。

### `/tools/futures-intro`

- 同一公开 URL 承载课程目录和当前学习关卡，不为 26 关创建大量薄内容 SEO 页面。
- 首次进入显示课程目录、路径选择和开始操作。
- 有有效本地进度时提供“继续学习”；当前章节展开，其他章节保持紧凑。
- 课程总览顶部提供明确的“返回工具”链接与紧凑当前位置，不在页尾重复同一出口。
- 进入关卡后采用固定顺序：核心对比、学习目标与术语、机制拆解、交互 / 引导式观察、
  完整教学案例、能力边界、三层理解检查、下一关。
- 关卡中的“返回目录”只返回课程目录，并同时保留明确的“返回工具”出口；用户还可以重新观察、
  重试或清除本地进度。

## 3. 课程范围

首版固定为五章二十六关：

1. 合约基础（5 关）：现货与永续、做多与做空、名义价值与保证金、订单类型、
   最新价 / 指数价 / 标记价。
2. 杠杆与风控（6 关）：杠杆、逐仓与全仓、强平与维持保证金、资金费率与费用、
   仓位风险预算、止盈止损与风险回报。
3. 读懂 K 线（4 关）：开高低收与影线、周期与闭合 K 线、成交量、市场结构与多周期。
4. 指标与关键区域（6 关）：EMA、均线排列与交叉、布林带、支撑压力区域、
   斐波那契、成交密集 / OI / 爆仓数据的使用边界。
5. 交易计划与回放（5 关）：趋势 / 震荡 / 突破、证据共振与冲突、触发 / 确认 / 失效、
   模拟计划、历史回放与毕业检查。

课程同时提供：

- 快速路径：从全部内容中选出 8 个核心关卡，约 45–60 分钟。
- 完整路径：依次完成全部 26 关，内容标注总计约 146 分钟，预留交互和重试后约 2.5–3 小时。
- 两条路径共用一份完成记录，不要求重复学习。

## 4. 每关内容合同

每个关卡必须包含：

- 稳定且唯一的关卡 ID、章节 ID 和课程内容版本。
- 简短中文标题、摘要和一个核心结论。
- “是什么”“为什么重要”“简单例子”“常见误区”和 3 个关键知识点。
- 2 个可验证学习目标、2–4 个关键术语、3–5 步机制拆解，以及包含前提、3 个步骤、
  观察结果和限制条件的完整教学案例。
- 明确列出本关“能帮助判断”和“不能直接告诉”的边界，并提供复盘句与下一课衔接。
- 8 个快速路径核心关必须有专属状态互动；其余完整路径关卡首版使用与主题对应的引导式图解和三个观察点，不用空动画冒充操作。
- 概念判断、情境应用、风险边界 3 道带 `fieldset / legend` 语义的选择题；三题均正确才完成本关。
- 每题有稳定 ID、合法答案 ID、错误解释和正确解释；答题事件只记录题型枚举，不记录答案。
- 是否属于快速路径，以及下一关关系。

答错允许重试，不扣分、不锁定、不制造时间压力。课程不记录原始答案文本、价格、账户金额、
收益、模拟盈亏或身份信息。

每个章节还必须包含本章导读、3 个学习目标和完成结果。目录只展示当前展开章节的导读，
避免 5 章正文同时堆叠。

## 5. 图表和示意数据

- 课程核心内容在市场 API 不可用时仍须完整可学习。
- 纯教学图必须明确标注“教学示意，不代表实时市场”，不显示会被误认作当前价格的数值。
- 历史训练片段必须来自已验证归档，并标注“历史训练片段，非实时行情”。
- 形成中的 K 线不能用于答案判定、突破确认或历史结果说明。
- 支撑与压力使用区域表达，不能描述成必然生效的精确点位。
- POC / 成交密集为 OHLCV 分桶估算时必须保留“估算”边界。
- 强平教学必须说明交易所、保证金模式、维持保证金档位和费用会改变真实结果。
- 历史结果只用于解释过去发生了什么，不能改写为未来概率或交易建议。

首版不要求课程运行时访问 Binance，也不允许 Client Component 直连任何第三方市场 API。
后续如接入真实历史练习，只能通过现有服务端标准化数据服务提供。

## 6. 进度与状态

进度使用带版本的本地状态，键名固定且不作为权限凭据。最小字段：

```ts
type CourseProgress = {
  schemaVersion: 2;
  contentVersion: "futures-intro-v2";
  path: "quick" | "full";
  currentLessonId: string;
  completedLessonIds: string[];
  quiz: Record<string, {
    status: "unanswered" | "retry" | "passed";
    attempts: number;
  }>;
  quizStages: Record<string, Partial<Record<
    "concept" | "scenario" | "boundary",
    {
      status: "unanswered" | "retry" | "passed";
      attempts: number;
    }
  >>>;
  updatedAt: string;
};
```

- 只在浏览器交互岛中访问 `localStorage`。
- 读取时执行 schema、版本、ID 和字段上限校验；损坏数据回退为空进度。
- 课程解锁状态由课程顺序和完成列表派生，不重复持久化。
- 三层测验分别保存最小状态；刷新或返回目录后可从已通过的题型继续，但不会保存用户选择的
  选项、答案文本或任何金融输入。旧版聚合进度会被安全迁移到 V2 状态。
- 清除进度需要明确确认，并只删除本课程键。
- 未来登录同步必须另行设计，当前本地进度不能证明 VIP、普通用户或真实身份。

## 7. Analytics 边界

允许的 provider-neutral 事件：

- `course_open`
- `lesson_start`
- `quiz_result`
- `lesson_complete`
- `course_complete`

事件仅允许课程版本、路径、章节 ID、关卡 ID、结果枚举和有界尝试次数等匿名枚举。
禁止发送选择的答案文本、选项 ID、价格、账户金额、金融输入、URL 查询、用户、Session、
本地存储内容或模拟结果。默认 adapter 继续为 noop，统计失败不能打断学习。
