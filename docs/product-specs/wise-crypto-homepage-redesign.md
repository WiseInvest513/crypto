# Wise Crypto 首页信息层级重设计

> 状态：已实现并通过最终生产预览验收
> 日期：2026-09-02
> 范围：仅重构 `/` 首页，不改变 BTC / ETH 数据 Provider、计算公式或 VIP 权限合同

## 1. 设计目标

首页首先回答三个问题：

1. BTC 与 ETH 当前价格和短期方向是什么？
2. 已闭合日线提供了哪些客观结构事实？
3. 用户下一步应该进入 K 线、VIP 人工策略还是风险工具？

原页面虽然信息完整，但各模块权重接近，Provider、scope、获取时间和缓存说明在每张
卡片重复出现，导致价格、变化与操作入口反而不突出。本轮不增加数据量，重点是建立
“先结论、再背景、最后审计细节”的阅读顺序。

## 2. 主站视觉对齐

以 Wise Invest Crypto 权益页为品牌参照，沿用以下特征：

- 白色与暖灰为主要页面表面，深色粗体承担标题层级。
- 琥珀色只用于权益与 VIP 价值强调，森林绿用于品牌、状态和主要导航。
- 内容使用较大的圆角、克制的软阴影和清晰边框，不用密集的小字号表格充满页面。
- 主标题、核心价格、模块标题、说明文字形成四级字号，不让所有文本处于同一权重。

## 3. 首页信息架构

```text
价值主张 + 全局更新时间
  └─ BTC / ETH 核心行情卡（价格、24h、7d、工作台入口）
      └─ 数据异常提示（仅异常时出现）
          └─ 市场现在（短期变化、BTC 日线、ETH 日线）
              └─ VIP 人工策略入口
                  └─ 当前有效的人工内容（无内容时不占位）
                      └─ 市场脉搏（4 项）
                          └─ 风险工具（4 项）
                              └─ 关键市场数据（默认收起）
```

BTC / ETH 详情入口只放在各自资产卡和 VIP 策略入口中；工具区只保留四个真正可执行的
计算器，避免把资产页、工具页和产品营销混在一个“下一步”列表里。

## 4. 数据展示与可信度

- `MarketDatum` 和 `DatumPresentation` 继续完整保留 `source`、`scope`、`updatedAt`、
  `retrievedAt`、`stale`、`cache`、`fallback` 与 error。
- 首页使用专门的紧凑时间视图，只显示更新时间；没有上游时间时明确写“检查于”。
- 首页不显示 Provider 名称、“查看数据口径”、缓存命中或底层派生来源，以减少视觉噪声。
- BTC / ETH 资产工作台继续使用完整元数据视图，数据审计能力没有删除。
- fresh、stale、error、unavailable、loading 仍是不同状态。失败或历史不足的日线事实
  会显示明确卡片，不静默消失；任何缺失值都不会用 `0` 代替。
- 人工内容的 sources 仍由 schema 和服务端解析校验；首页只显示审核与有效期。

## 5. 响应式规则

### Desktop

- BTC / ETH 使用两列同权大卡。
- “市场现在”使用一张强调卡加两张日线卡。
- 市场脉搏和风险工具各为四列。
- 深层数据默认收起，减少首页扫描长度。

### Tablet

- “市场现在”的短期变化占满第一行，BTC / ETH 日线并列。
- VIP 操作移动到第二行三列。
- 工具改为两列。

### Mobile

- 16px 页面边距，BTC / ETH 与市场事实全部自然纵向排列。
- 不使用横向滑动隐藏核心事实。
- 操作行和链接保留至少约 44px 的触控高度。
- 市场脉搏在常见手机宽度为 2×2；窄于 352px 时变为单列。

## 6. 实现边界

- 不新增第三方请求，不改变 Provider 选择或缓存策略。
- 不生成自动多空结论、支撑、阻力、目标价或“适合买卖”等文案。
- 不创建登录、Session 或客户端 VIP 开关。
- 不恢复产品目录；Crypto 权益仍由 Wise Invest 主站承接。
- 不在首页绘制没有可靠历史输入的装饰性 sparkline。

## 7. 验收标准

- 第一屏能同时发现页面价值主张、BTC/ETH 价格、24h/7d 变化和 K 线工作台入口。
- 首页正文不出现 Provider 名称或“查看数据口径”，但服务端数据合同与资产详情仍保留来源。
- 320px、390px 和桌面宽度无全局横向溢出，核心事实不依赖横向滚动发现。
- unavailable/error 状态不会导致三条“市场现在”卡片静默缺列。
- 键盘可访问资产、VIP、工具及深层数据展开入口。
- `lint`、`typecheck`、`tests`、`production build` 全部通过，生产预览固定在 2222 端口。
