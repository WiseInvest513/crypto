# Wise Crypto 工具工作台重设计

> 状态：已实现，并通过生产预览验收
> 日期：2026-09-02；目录布局更新：2026-09-03
> 范围：`/tools` 与四个既有计算器；不修改计算公式、数据 Provider 或 Analytics 安全边界

## 1. 设计目标

原工具功能、公式和输入校验已经完整，但页面以“功能目录、说明、公式、结果”平铺，用户
进入后需要先读懂产品结构，才能开始自己的任务。本轮将体验改成一条清晰路径：

```text
选择当前问题
  → 填写必要输入
    → 看到一个核心结果
      → 按需展开公式与边界
        → 进入中性的下一步
```

工具继续只做机械计算，不给默认风险比例、默认杠杆、推荐价位、方向判断或收益承诺。

## 2. 视觉方向

工具页使用与新版首页、Wise Invest 主站一致的白色与浅灰画布、深墨色粗标题、森林绿
主操作和低饱和浅绿色信息面。琥珀、蓝和紫只用来区分不同任务类型，不承担涨跌或好坏
判断。工具目录明确使用四张同权悬浮方块；计算器详情页不滥用重复卡片，也不使用
Crypto 霓虹、深色交易所界面或大量小号来源文字。

## 3. 工具中心信息架构

- 首屏标题直接回答产品价值：交易前先把风险算清楚。
- 仓位、杠杆、历史 DCA 与风险回报改为四张同尺寸、同权重的独立方块；不使用
  “推荐”“主要工具”或编号形成隐性排名。
- 每张方块均展示独立线性 SVG 图标、用户问题、必要输入、核心结果和打开操作；绿色、
  琥珀、蓝色与紫色只用于帮助辨认工具，不表达好坏或推荐顺序。
- Desktop 四列并排；中等宽度两列；Mobile 单列。卡片使用轻阴影与克制的 hover 上浮，
  并尊重 `prefers-reduced-motion`。
- 删除重复的“怎么选择”说明带，避免四个入口下方再次形成解释层级。
- 隐私说明压缩为单一信任提示：输入只在当前设备计算，不保存、不进入匿名统计。

`toolCatalog` 是入口和页面文案的单一数据源，集中维护 `category`、`question`、
`inputSummary`、`resultSummary` 与 `primaryOutput`。首页快捷入口也从同一目录派生，避免
工具名称、顺序和用途说明长期漂移。

## 4. 计算器工作区

四个详情页共用一个任务工作台：

- 紧凑面包屑、问题式标题、本地计算提示和复制工具链接。
- 三段流程条说明当前页面的输入、检查和结果关系，但不是需要切换的伪步骤组件。
- Desktop 为左侧输入、右侧结果；Mobile 按 DOM 顺序自然排列为输入后结果。
- 公式、输出和未计因素移入原生 `<details>`，在计算前不抢占主要视线。
- 下一步只打开空白工具或资产工作台，不传递金融输入和结果。

核心结果层级：

| 工具 | 首要结果 | 次要结果 |
|---|---|---|
| 仓位风险 | 按当前输入估算的资产数量 | 名义仓位、最大风险金额、单位价格风险 |
| 杠杆与盈亏 | 初始保证金 | 情景盈亏、仓位数量、保证金 ROE |
| 风险回报 | 中性的 `1:x` | 每单位风险、每单位潜在回报 |
| 历史 DCA | 历史期末价值 | 总投入、累计数量、平均成本、历史盈亏和收益率 |

DCA 的来源、scope、数据截至时间、获取时间、cache 和错误状态仍完整保留，只在 fresh
状态下进入“完整数据口径”展开项；error / unavailable 会默认展开，且无法取得可靠日线
时继续禁止计算，不生成模拟结果。

## 5. 无障碍与移动端

- 保留原生 `form`、`fieldset`、`legend`、`label`、radio、select 和按钮语义。
- 字段 hint 在报错后仍可见，输入同时关联 hint 与 error；字段错误不再并发触发多条
  `role=alert`。
- 提交失败优先聚焦首个无效字段；只有通用计算错误时才聚焦错误摘要。
- 结果只播报简短状态标题，不把全部数字、说明和警告作为 atomic live region 重读。
- 每次复制链接都会产生新的读屏反馈；目录和下一步使用真实列表语义。
- 320 / 390px 使用单列，输入和主按钮保持至少 44px 触控区域，DCA 明细只在内部横向
  滚动，不产生页面级横向溢出。

## 6. 保持不变的安全边界

- 四个独立公开 URL、中文 metadata、canonical、Open Graph 与 sitemap 不变。
- 仓位、杠杆、风险回报的纯函数公式和方向校验不变。
- 杠杆工具继续不计算通用强平价。
- 风险回报比继续使用中性色，不按比值标记好坏。
- DCA 继续只使用 Binance Spot 已闭合 UTC 日线，并保留月末、下一根有效日线等规则。
- `tool_open` / `tool_complete` 只记录允许字段；余额、价格、比例、金额、结果不会进入
  Analytics。
- 不新增交易、登录、VIP 判断或第三方客户端请求。

## 7. 验收标准

- `/tools` 首屏能够发现四个同权工具；Desktop 四列卡片尺寸与视觉权重一致。
- 四个详情页第一屏能够同时理解输入任务与结果区域，不再先看到公式说明栏。
- 成功计算后核心结果在视觉上明显高于辅助结果，且自动带入可见区域。
- 空提交能把焦点送到首个错误字段，提示和单位说明不会消失。
- 320、390 和桌面宽度无页面级横向溢出；键盘可完成表单、分享和 disclosure。
- `pnpm lint`、`pnpm typecheck`、`pnpm test` 与 `pnpm build` 全部通过，生产预览运行在
  `http://localhost:2222`。
